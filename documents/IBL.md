## 计算
### 1. 环境漫反射：球谐光照

投影到 **三阶球谐函数（Spherical Harmonics, SH）**。

#### 解释
由论文An efficient representation for irradiance environment maps的方法，计算球谐系数：

光照分布$L(\theta,\phi)$的球谐系数$L_{lm}$的积分定义，对于$l≤2$（0阶、1阶、2阶）的9个核心系数，计算式为：
$$L_{l m}=\int_{\theta=0}^{\pi} \int_{\phi=0}^{2 \pi} L(\theta, \phi) Y_{l m}(\theta, \phi) \sin \theta d \theta d \phi$$
其中：
1. $L(\theta,\phi)$：环境贴图在球面坐标$(\theta,\phi)$处的辐亮度（Radiance），即环境贴图的像素值；
2. $Y_{lm}(\theta,\phi)$：**低阶球谐基函数**（论文已在2节给出$l≤2$的所有显式数值表达式，共9个）；
3. $\sin\theta d\theta d\phi$：球面的面积元，是球面积分的标准权重；
4. 计算需对**RGB三个颜色通道分别执行**，最终$L_{lm}$为RGB三维值。

论文将上述连续积分转化为**离散的像素加权求和**，适配计算机对环境贴图（离散像素）的处理，核心思路为：
> 积分运算等价于**环境贴图中所有像素的辐亮度$L$，与对应位置的球谐基函数$Y_{lm}$值做加权乘积，再对所有像素求和**。

即把连续的积分操作，转化为对环境贴图像素集合的求和操作：
$$L_{lm} \approx \sum_{pixels} L(p) \cdot Y_{lm}(p) \cdot w(p)$$
其中$w(p)$为像素$p$对应的球面面积元权重（离散化的$\sin\theta d\theta d\phi$），论文指出这一操作本质是**计算光照的矩（moments）**，或$L$与$Y_{lm}$的内积。

**计算的效率与维度说明**
1. **仅计算9个系数**：论文的核心结论是辐照度（Irradiance）仅对低阶光照频率敏感，因此只需计算$l=0$（1个）、$l=1$（3个）、$l=2$（5个）共9个系数，计算复杂度为$O(9S)$（$S$为环境贴图总像素数）；
2. **独立处理颜色通道**：每个$L_{lm}$系数均包含R、G、B三个分量，需对每个通道单独执行上述加权求和，最终得到9×3的系数集合；
3. **预处理执行**：该计算作为**预滤波（Prefiltering）** 步骤离线执行

论文已直接给出$l≤2$的所有球谐基函数$Y_{lm}(\theta,\phi)$的显式数值表达式（笛卡尔坐标/球面坐标形式），无需额外推导，直接代入计算即可，这是实现$L_{lm}$计算的关键前提（论文2节公式3）。


### 2. 环境镜面反射：Split Sum（拆分求和）

镜面反射受粗糙度的影响。它被拆分为两部分：

- **Part A: Pre-filtered Radiance Map（预过滤环境图）**
    - **做法**：将天空盒生成带有 **Mipmaps** 的纹理。
    - **算法**：Mip 0 存储最清晰的反射（Roughness = 0，分辨率是512px），随着 Mip 等级提高，贴图越来越模糊（对应 Roughness 越来越大），分辨率越来越低。
    - **渲染时**：根据材质的 `Roughness` 值，使用 `textureLod` 函数在不同的 Mip 层级间进行插值采样。

使用compute shader+重要性采样来生成。

| **Mip 等级** | **分辨率** | **对应的 Roughness (约值)** | **采样策略**      |
| ---------- | ------- | ---------------------- | ------------- |
| **Mip 0**  | 512     | 0.0 (完美镜面)             | 直接拷贝原图，无需采样   |
| **Mip 1**  | 256     | 0.2                    | 128 - 256 次采样 |
| **Mip 2**  | 128     | 0.4                    | 512 次采样       |
| **Mip 3**  | 64      | 0.6                    | 1024 次采样      |
| **Mip 4**  | 32      | 0.8                    | 1024 次采样      |
| **Mip 5**  | 16      | 1.0 (全散射)              | 2048 次采样      |
Mipmap 采样偏移
生成 Pre-filtered Map 的 Shader 里，不要直接从环境图的 Mip 0 采样，而是根据该采样点的 PDF（概率密度），计算一个 **Lod Bias**。
- 如果某个方向的采样点很稀疏（PDF 小），就去采样环境图里更模糊的 Mip 层。
- 这样相当于用“模糊”来抵消“噪声”，能用极少的采样数得到非常平滑的高光过渡。****


- **Part B: BRDF LUT（查找表）离线积分贴图
  使用一张预计算的 2D 查找表（Look-Up Table, LUT）。
- "\resource\textures\BRDFLUT.dds"
	- **横坐标**：$N \cdot V$（观察角度）。
	- **纵坐标**：粗糙度。

采样器设置为 `Clamp to Edge，`格式：VK_FORMAT_R16G16_SFLOAT


- GGX实现 参考自Unreal4
```cpp
float D_GGX( float Roughness, float NoH )
{
	float a = Roughness * Roughness;
	float a2 = a * a;
	float d = ( NoH * a2 - NoH ) * NoH + 1;	// 2 mad
	return a2 / ( PI*d*d );			// 4 mul, 1 rcp
}
```
